Кликабельный прототип интерфейса Work Day и тесты движка смены.

```bash
node --test engine.test.js   # модель, планирование, риск-модель, рендер всех экранов
python3 -m http.server 8137 --bind 0.0.0.0 && open http://localhost:8137
```

`app.js` — тот же движок, что в `../android/.../domain/engine/ShiftEngine.kt` (фазы смены, тики по 6 минут,
24 действия, остановка на одобрении). Рендер-функции (`viewShift` и др.) — текстовые двойники Compose-экранов:
тесты гоняют их и ловят `undefined`/`NaN` в разметке.

Это **не** код приложения: он нужен, чтобы смотреть дизайн и проверять логику без Android SDK.
