# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-22

Первая версия NEXUS Firmware Studio. Проект переписан с нуля на C#/.NET 10; предыдущий
Python-прототип удалён из репозитория.

### Добавлено

**Приложение**

* WPF-интерфейс (MVVM) с 14 разделами: обзор, устройства, прошивки, прошивание, ADB/Fastboot,
  Qualcomm, MediaTek, Samsung, извлечение, разделы, журнал, драйверы, плагины, настройки.
* Тёмная тема, русский и английский интерфейс, панель журнала, прогресс операций.
* Автоматическое обнаружение устройств по таймеру (ADB, Fastboot, USB/Windows).

**Ядро и инфраструктура**

* Доменные модели с честной семантикой «неизвестно = `null`», план операции с рисками и
  проверками совместимости.
* Запуск внешних процессов через `ArgumentList` с таймаутами и редакцией вывода.
* SQLite: каталог прошивок, заметки, история импорта, снимки устройств, отчёты, журнал,
  доверенные издатели и их открытые ключи.
* Serilog с ротацией, `ILogBus` с маскированием идентификаторов.
* Очередь заданий (`JobQueue`) с прогрессом, отменой между шагами и формированием отчёта.
* Отчёты в Markdown и JSON.

**Прошивки**

* Определение форматов по сигнатуре: ZIP, TAR/TAR.MD5, GZIP, LZ4 frame, sparse, boot.img,
  payload.bin, MediaTek scatter, Qualcomm rawprogram XML.
* Безопасная распаковка: нормализация путей, запрет `..`/абсолютных путей/ADS/зарезервированных
  имён, лимиты объёма и количества записей.
* LZ4 frame: потоковое декодирование блоков с проверкой xxHash32 (заголовок, блоки, содержимое).
* Sparse: разбор чанков RAW/FILL/DONT_CARE и преобразование в raw-образ.
* payload.bin: разбор protobuf-манифеста и списка разделов.
* Samsung: разбор AP/BL/CP/CSC/HOME_CSC, модель, PDA/CSC, ревизия загрузчика, проверка набора.
* Сравнение прошивок и проверка совместимости с устройством.

**Прошивание**

* Планировщик с `DryRun` по умолчанию.
* Стратегии: Fastboot (образы и архивы), ADB sideload; для Samsung/MediaTek/Qualcomm — честная
  подготовка плана и отчёта без выполнения закрытых протоколов.
* Тройное подтверждение реальной записи, отдельное подтверждение очистки данных.
* Проверки: модель, регион, загрузчик, целостность, anti-rollback, свободное место.

**Сервисные модули**

* Qualcomm: поиск EDL-устройств, проверка firehose/rawprogram/patch, отчёт.
* MediaTek: поиск BROM/Preloader, разбор scatter, проверка файлов, порядок операций.
* Samsung: анализ пакета, раскладка для официального инструмента, отчёт.
* Драйверы: инвентаризация, официальные источники, проверка подписи установщика
  (`Get-AuthenticodeSignature`), инструкции по переустановке.

**Плагины**

* Манифест с моделями, драйверами, операциями, проверками, форматами и лимитами.
* Проверка SHA-256 сборки, издателя, версии хоста и отсоединённой подписи манифеста (RSA-SHA256,
  ключ издателя в хранилище).
* Загрузка внешних сборок выключена по умолчанию, встроенный модуль `GenericAndroidPlugin`.

**Тесты и CI**

* NUnit: юнит-тесты парсеров, безопасности, планировщика и доверия плагинам; интеграционные —
  SQLite, библиотека прошивок, извлечение, обнаружение устройств.
* GitHub Actions: тесты на Ubuntu, сборка WPF и публикация self-contained EXE на Windows, сборка
  установщика Inno Setup, публикация релиза.

### Безопасность

* Запись только после явных подтверждений; блокирующие проверки отменяют план.
* Маскирование серийных номеров и IMEI, отсутствие телеметрии.
* Оригинальные файлы прошивок не изменяются.
* Проверка подписи драйверов не отключается; протоколы производителей не обходятся.

### Известные ограничения

* Samsung Odin, MediaTek BROM/SLA/DAA, Qualcomm EDL/Firehose — только подготовка и отчёт.
* `payload.bin` не распаковывается по операциям (только манифест).
* Интерфейс и все внешние инструменты работают только на Windows.
