# Изменения

## 0.1.0 — MVP

**Первый публичный релиз:** установщик и портативная сборка для Windows 10/11
опубликованы в [Releases](https://github.com/Klavish777/test/releases/tag/v0.1.0).

### Исправлено после первого прогона сборки

- **Сборка Windows падала** (`script '.../main.py' not found`): в
  `build/smartphone_repair_os.spec` корень проекта вычислялся как
  `Path(SPECPATH).parent`, хотя `SPECPATH` — это каталог со spec-файлом.
- **Кириллица в перенаправленном выводе на Windows** (cp1252) вызывала
  `UnicodeEncodeError`; добавлен `configure_console()` — UTF-8 в `stdout`/`stderr`
  и подмена отсутствующих потоков для сборки без консоли.
- `--check` больше не требует графической подсистемы: базу можно проверить в CI,
  на сервере и в собранном EXE без экрана.
- Имя установщика ломалось, если версия приходила из имени ветки (`refs/...` с `/`):
  версия санитайзится, в CI берётся из `repair_os/version.py`.
- Скрипт сборки: полный лог шагов в `build/logs`, хвост лога и аннотация `::error::`
  при сбое, обязательная проверка установщика (`-RequireInstaller`), дымовой запуск
  собранного EXE, портативный ZIP.
- **Таблицы каталога, прошивок и библиотеки больше не обрезают столбцы:**
  ширины считаются от содержимого (`FittedTableView`), второстепенные колонки
  скрываются по приоритету при нехватке места.

### Содержимое первого этапа

### Добавлено

**Этап 1 — каркас и интерфейс**
- Запускаемое приложение PySide6 с тёмной темой (графит/тёмно-синий, синие акценты),
  компактной левой навигацией, центральной областью и статус-баром.
- Главная страница: поиск, разделы 3D BoardView / Firmware Center / Technical Library,
  популярные бренды, недавние и избранные устройства, счётчики.
- Система переводов (JSON-каталоги `ru`/`en`), логирование с ротацией, обработчик
  необработанных исключений.

**Этап 2 — каталог**
- 14 брендов, каталог только по брендам и моделям, таблица и карточки, фильтры,
  сортировки, избранное, история открытий, варианты устройства.

**Этап 3 — база данных и импорт**
- SQLite-схема (14 требуемых таблиц + `board_annotations` и `audit_log`), индексы,
  внешние ключи, CHECK-ограничения, миграции с контрольными суммами.
- Импорт CSV/JSON (dry-run, затем запись), шаблоны, экспорт JSON, журнал изменений.

**Этап 4 — Firmware Center**
- Список с фильтрами и сортировками, карточка записи, источники, статусы проверки,
  проверка совместимости по коду модели/региону/загрузчику, проверка SHA-256,
  прикрепление локального файла с подтверждением, история изменений.

**Этап 5 — Technical Library**
- Документы (PDF, схемы, BoardView, фото, инструкции, заметки, ссылки), категории узлов,
  теги, статусы достоверности с датой проверки, права на использование, заметки мастера,
  справки по компонентам.

**Этап 6 — 3D BoardView**
- Собственный программный 3D-рендер: вращение, зум, панорама, обе стороны, выбор и
  подсветка компонентов, позиционные обозначения, слои и типы, карточка компонента,
  поиск по обозначению, метки и заметки, снимки вида.
- Формат пакетов `smartphone-repair-os-board` v1: импорт/экспорт JSON и ZIP, безопасная
  распаковка, явное предупреждение при отсутствии 3D и фоторежим с метками.

**Этап 7 — надёжность и сборка**
- Резервное копирование ZIP с манифестом и SHA-256, восстановление со страховочной
  копией и проверкой целостности/версии схемы.
- 73 автотеста (БД, безопасность, репозитории, сервисы, UI smoke).
- Сборка Windows: PyInstaller spec, Inno Setup, скрипты `build_windows.ps1`/`.bat`,
  GitHub Actions (тесты + EXE + установщик + Release по тегу).
- Заготовка лицензирования (`core/entitlements.py`) без обязательной оплаты.

### Известные ограничения
- Демонстрационные данные помечены `ДЕМО`; ссылки ведут на `example.org`.
- Внешние форматы BoardView (`.brd`, `.bdv`, `.pcb`) требуют конвертации в JSON.
- 3D-рендер программный: нет теней/шейдеров, корпуса — параллелепипеды.
- Нет аккаунта, синхронизации и оплаты (архитектура подготовлена).
- Нет встроенного просмотрщика PDF (файл открывается системным приложением).
