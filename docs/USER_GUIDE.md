# Руководство мастера

## 1. Первый запуск

Приложение создаёт каталог данных:

* Windows: `%LOCALAPPDATA%\SmartphoneRepairOS`
* Linux: `~/.local/share/smartphone-repair-os`
* macOS: `~/Library/Application Support/SmartphoneRepairOS`

Внутри: `db/` (SQLite), `firmware/`, `library/`, `boards/`, `backups/`, `logs/`.

При первом запуске загружаются **демонстрационные** данные (помечены `ДЕМО`).
Удалить их: **Настройки → Данные и файлы → Удалить демо-данные**.

## 2. Поиск

Строка поиска вверху (или `Ctrl+K`). Ищет одновременно по:

* устройствам (название, бренд, точный код модели, кодовое имя, процессор);
* прошивкам (имя файла, код модели, номер сборки);
* материалам библиотеки (название, описание, теги, устройство);
* платам и компонентам.

Точный код (`SM-A525F`) поднимается в начало результатов. `Enter` открывает страницу
результатов, клик по элементу — соответствующий раздел.

## 3. Каталог и карточка устройства

* Слева — бренды с числом моделей; выше — «Все бренды».
* Фильтры: «Избранные», «С 3D», сортировка (название / код / год / изменение).
* Переключение вида «Таблица ↔ Карточки» — кнопка **Вид**.
* Двойной клик — карточка устройства.
* Контекстное меню (правая кнопка) — избранное, прошивки, BoardView, изменение, удаление.

В карточке: технические данные, варианты (регион/CSC/загрузчик), BoardView, прошивки,
материалы, заметки.

## 4. 3D BoardView

| Действие | Как |
|---|---|
| Вращение | левая кнопка мыши + движение |
| Панорама | правая кнопка (или `Shift` + ЛКМ) |
| Зум | колесо мыши, `+` / `−` |
| Обратная сторона | кнопка **Реверс** или `S` |
| Сброс камеры | **Сброс** или `F` |
| Вид сверху / сбоку | соответствующие кнопки |
| Выбор компонента | клик по корпусу, по метке на фото или по строке в списке |
| Поиск по обозначению | поле «Обозначение (U1201)…» + `Enter` |
| Скрыть слой/тип | снять галочку в левой панели |
| Метка/заметка | кнопки **Метка** / **Заметка** в карточке компонента |
| Снимок вида | **Снимок** → PNG |

Вкладка **«Фото с метками»** — режим для плат без 3D или для сопоставления с фото:
колёсико — масштаб, перетаскивание — панорама, клик по метке — выбор компонента.

Если для платы нет 3D-данных, приложение явно показывает предупреждение и
переключается на фоторежим — оно не подменяет 3D статичной картинкой.

## 5. Firmware Center

1. Выберите бренд → устройство (или ищите по файлу/сборке).
2. В таблице: файл, модель, ОС, сборка, регион/CSC, дата, размер, источник, статус.
3. Справа — подробности и действия.

**Проверить совместимость** — приложение сравнивает точный код модели с устройством,
регион/CSC с вариантами, минимальный загрузчик и наличие контрольной суммы.
Результат: «явных проблем нет» / «есть предупреждения» / «несовместимо».

**Прикрепить локальный файл…** — требует подтверждения (ввод `ПОДТВЕРЖДАЮ`), затем
проверяет расширение, целостность ZIP и SHA-256, копирует файл в локальную библиотеку.

**Проверить контрольную сумму** — сверяет файл с эталонной SHA-256 записи.

**История изменений** — журнал создания/изменений/проверок.

## 6. Technical Library

Категории соответствуют узлам: питание, зарядка, USB, RF, аудио, дисплей, камеры,
датчики, память, процессор, ПО, общее. Материал привязывается к устройству, имеет
теги, источник, права и статус проверки.

Кнопка **Открыть файл** открывает приложенный документ системным просмотрщиком,
**Открыть ссылку** — источник в браузере (после подтверждения).

## 7. Резервные копии

**Резервная копия → Создать копию** (или `Ctrl+B`). Копия — ZIP:

```
manifest.json        версия, дата, SHA-256 всех файлов
repair_os.sqlite3    консистентная копия базы (SQLite backup API)
attachments/…        материалы библиотеки (по выбору)
```

**Восстановление**: выберите копию → подтвердите (`ВОССТАНОВИТЬ`). Перед заменой
автоматически создаётся страховочная копия, после — проверяются целостность и версия
схемы. Копии из более новой версии приложения отклоняются.

Рекомендуется держать копии на отдельном носителе и делать их перед массовым импортом.

## 8. Настройки

* Язык интерфейса (применяется после перезапуска).
* Показ пометки `ДЕМО`, подтверждение опасных операций.
* Каталог данных, создание/восстановление копий, экспорт JSON.
* Диагностика: количество записей, целостность базы, `VACUUM`, каталог логов.
* Сведения о лицензии: в MVP все функции доступны, оплата не требуется.

## 9. Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+K` | фокус в строке поиска |
| `Ctrl+N` | новое устройство |
| `Ctrl+B` | резервная копия |
| `F5` | обновить текущую страницу |
| `F` / `S` | сброс камеры / обратная сторона (BoardView) |
| `←` `→` `↑` `↓` | поворот камеры (BoardView) |

## 10. Если что-то пошло не так

* Логи: **Настройки → Диагностика → Открыть каталог логов** (`logs/repair_os.log`,
  ротация по 2 МБ, 5 файлов).
* Проверка базы без интерфейса: `SmartphoneRepairOS.exe --check` (или
  `python main.py --check`).
* Повреждённые данные: восстановите последнюю копию.
* Пустое окно после обновления: возможно, повреждён каталог данных — переименуйте его,
  приложение создаст новый; затем восстановите копию.
