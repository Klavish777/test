# Руководство пользователя

Приложение состоит из 14 разделов. Левая панель — навигация, верхняя строка — устройство,
режим работы и быстрые действия, нижняя строка — состояние ADB/Fastboot и последняя операция.

Первое, что стоит сделать после запуска — открыть **Настройки** и указать пути к `adb`/`fastboot`,
если они не в `PATH`, затем **Устройства → Обновить**.

## 1. Обзор

Сводка: количество подключённых устройств, активное устройство и его режим, состояние
инструментов, последняя операция с прогрессом, последние отчёты. Кнопка «Обновить устройства»
запускает обнаружение вручную.

## 2. Устройства

Таблица всех найденных устройств: режим (ADB, Fastboot, EDL, BROM, Download, USB), модель,
производитель, серийный номер (маскирован), состояние драйвера, предупреждения. Выбор устройства
здесь задаёт его для всех остальных разделов.

«Проверить устройство» запрашивает `getprop`/`getvar` и показывает «карточку» с версией Android,
сборкой, слотом, состоянием загрузчика. Если данные недоступны, поле остаётся пустым — приложение
не придумывает значения.

## 3. Прошивки (библиотека)

* **Импорт файла / папки** — добавляет прошивку в библиотеку, считает SHA-256, определяет формат,
  находит дубликат по хэшу.
* **Проверить хэш** — пересчитывает и сравнивает с сохранённым; при расхождении помечает
  `Integrity = Failed`.
* **Совместимость** — выбранная прошивка против выбранного устройства: модель, производитель,
  регион, загрузчик, целостность, anti-rollback.
* **Сравнить** — две прошивки: метаданные, список файлов, различия.
* **Заметки** — произвольный текст, хранится в базе.

Двойной щелчок по строке открывает подробности и список компонентов.

## 4. Прошивание

1. Выберите устройство и прошивку.
2. Оставьте **Dry Run** включённым и нажмите «Построить план»: приложение проверит совместимость,
   целостность, свободное место и покажет шаги, риски и предупреждения. На устройство не
   отправляется ни одной команды записи.
3. Чтобы выполнить реальную запись, снимите Dry Run, включите «Разрешить изменение устройства»,
   постройте план заново и нажмите «Выполнить». Приложение попросит ввести серийный номер
   устройства — это защита от случайного запуска на другом телефоне.
4. Прогресс и журнал видны внизу; по завершении создаётся отчёт (Markdown + JSON).

Ограничения показываются прямо в плане: например, для Samsung Download mode план блокируется с
пояснением, что протокол Odin не реализован и нужно использовать официальный инструмент.

## 5. ADB и Fastboot

Безопасные диагностические команды:

* ADB: `devices`, `getprop`, `shell` из белого списка (`getprop`, `dumpsys battery`, `pm list
  packages` и т.п.), `logcat`, перезагрузка в систему/bootloader/recovery/sideload.
* Fastboot: `devices`, `getvar all`, список разделов с размерами, перезагрузка, установка
  активного слота.

Кнопка «Копировать» копирует вывод в буфер, «Сохранить отчёт» — в файл. Опасные команды
(`flash`, `erase`, `format`, `-w`) в этом разделе недоступны: для них есть раздел «Прошивание» с
подтверждениями.

## 6. Qualcomm Service

Определяет устройства в режиме EDL (VID 05C6 / PID 9008), проверяет пакет: наличие firehose
programmer, `rawprogram*.xml`, `patch*.xml`, размеры и хэши файлов. Формирует отчёт с порядком
разделов. **Не** отправляет firehose и не работает с Sahara — для записи используется официальный
инструмент производителя.

## 7. MediaTek Service

Определяет BROM/Preloader, разбирает `scatter` (платформа, проект, разделы, размеры, регионы),
проверяет наличие файлов и соответствие размеров, показывает порядок загрузки и отчёт. **Не**
работает с BROM-протоколом, DA/SLA/DAA и не обходит защиту — только подготовка для SP Flash Tool.

## 8. Samsung Service

Разбирает имена `AP_/BL_/CP_/CSC_/HOME_CSC_` пакетов (модель, версия PDA, CSC, ревизия
загрузчика), проверяет совместимость модели и региона, сообщает о нехватке компонентов, формирует
раскладку файлов для Odin и отчёт. Запись в Download mode приложением не выполняется.

## 9. Извлечение прошивок

Анализ файла без изменения оригинала: формат, размер, SHA-256, секции (архив, образы, payload,
scatter, rawprogram), предупреждения и **ограничения**. Кнопки:

* «Извлечь» — распаковка в выбранный каталог или временную папку;
* «Экспорт JSON» / «Экспорт CSV» — отчёт анализа;
* «Открыть каталог» — проводник.

Оригинальный файл не изменяется никогда; при опасном архиве извлечение отклоняется.

## 10. Разделы

Список разделов выбранного устройства (из `getvar all`/`by-name`), размеры, тип (логический/
физический), свободное место. Действия: перечитать список, скопировать таблицу, сохранить отчёт.
Запись и стирание здесь не выполняются.

## 11. Журнал и диагностика

Поток событий приложения с уровнями и фильтрами, список сохранённых отчётов, экспорт журнала и
сводный диагностический отчёт (окружение, инструменты, устройства, последние операции).
Серийные номера маскируются, если включена соответствующая настройка.

## 12. Драйверы

Инвентаризация USB-устройств и проблемных драйверов с кодами ошибок, ссылки на официальные
источники, инструкция по переустановке, проверка подписи установщика (издатель, отпечаток,
метка времени). Приложение не устанавливает драйверы и не отключает проверку подписей.

## 13. Плагины

Список встроенных и внешних модулей, политика доверия, доверенные издатели. Внешние плагины
загружаются только при включённом флаге, совпадении SHA-256 и доверенном издателе; отклонённые
модули показываются с причиной.

## 14. Настройки

Язык (ru/en), тема, интервал обновления устройств, режим «только чтение», обязательное
подтверждение серийным номером, маскирование номеров в журнале, срок хранения журналов, пути к
`adb`/`fastboot`, каталог библиотеки и извлечения, загрузка плагинов, канал обновлений и проверка
обновлений (по явной команде).

## Что делать, если что-то не работает

1. **Устройство не найдено.** Проверьте кабель и режим (ADB/Fastboot/Download). В разделе
   «Драйверы» посмотрите код проблемы; при `28` (нет драйвера) установите официальный драйвер.
2. **`unauthorized`.** Разблокируйте экран и подтвердите отладку по USB на устройстве.
3. **План заблокирован.** Прочитайте список проверок: чаще всего это заблокированный загрузчик,
   несовпадение модели или непроверенная целостность файла.
4. **Запись прервалась.** Не отключайте кабель; перезапустите диагностику и повторите план.
   Приложение сохранит отчёт с точным шагом, на котором произошёл сбой.
