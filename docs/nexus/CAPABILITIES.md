# Возможности и ограничения

Документ фиксирует **фактическое** состояние: что приложение делает само, что делает частично и
чего не делает. Он обновляется вместе с кодом; если функции нет в таблице «Реализовано», считать
её отсутствующей.

Обозначения: ✅ реализовано и покрыто проверками · ⚠️ частично (указано, что именно) ·
🚫 не реализовано (осознанно, с объяснением).

## Обнаружение устройств

| Функция | Статус | Детали |
|---------|--------|--------|
| Список ADB-устройств | ✅ | `adb devices -l`, состояния `device/unauthorized/offline` различаются |
| Свойства Android | ✅ | `getprop`, модель, кодовое имя, версия, `ro.boot.flash.locked` |
| Fastboot-устройства | ✅ | `fastboot devices`, `getvar all`, слот, размеры разделов |
| USB-устройства Windows | ✅ | `Get-PnpDevice`, VID/PID, состояние драйвера, код проблемы |
| Режим Qualcomm EDL, MediaTek BROM, Samsung Download | ⚠️ | определяется по VID/PID и имени драйвера; ничего не пишется |
| Идентификация модели без ADB/Fastboot | 🚫 | невозможна без протокола производителя; поле остаётся пустым |
| Скрытие серийных номеров в интерфейсе и журнале | ✅ | `Redactor`, настройка `MaskSerialsInLogs` |

## Прошивание

| Операция | Статус | Условия |
|----------|--------|---------|
| План записи Fastboot (dry-run) | ✅ | ничего не выполняется на устройстве |
| Запись образов через Fastboot | ✅ | bootloader разблокирован, `DryRun=false`, `AllowDeviceModification=true`, подтверждение серийным номером |
| ADB sideload | ✅ | устройство в режиме sideload, целостность подтверждена |
| Очистка пользовательских данных (`-w`) | ✅ с отдельным подтверждением | `WipeUserData=true` **и** `ConfirmDataWipe=true` |
| Разблокировка загрузчика | 🚫 | не выполняется: это необратимая операция, требующая согласия владельца и стирания данных |
| Samsung Download mode / Odin | 🚫 | протокол закрытый; только анализ пакета, план и отчёт для официального инструмента |
| MediaTek BROM / SP Flash Tool | 🚫 | только `scatter`-проверки и подготовка каталога для официального инструмента |
| Qualcomm EDL / Firehose | 🚫 | только проверка `rawprogram`/`patch` и отчёт |
| Обход подписи, SLA/DAA, Secure Boot, FRP, блокировки аккаунта | 🚫 | никогда, ни в каком режиме |

## Сервисные модули

| Модуль | Что делает | Чего не делает |
|--------|------------|----------------|
| Qualcomm | находит EDL-устройства, проверяет пакет прошивки (firehose programmer, rawprogram/patch XML, хэши), формирует отчёт | не отправляет firehose, не работает с Sahara |
| MediaTek | находит BROM/Preloader-устройства, разбирает scatter, проверяет наличие файлов, формирует порядок и отчёт | не работает с BROM-протоколом и DA |
| Samsung | находит Download mode, разбирает имена AP/BL/CP/CSC, проверяет модель/регион/ревизию, готовит раскладку для Odin | не отправляет Odin-пакеты |
| Драйверы | инвентаризация, официальные ссылки, проверка подписи установщика (`Get-AuthenticodeSignature`), инструкции | не устанавливает драйверы и не отключает проверку подписей |
| Плагины | манифест, SHA-256 сборки, доверенный издатель, выключенная по умолчанию загрузка | не загружает неподписанные сборки, не исполняет код из интернета |

## Совместимость по производителям

Общая поддержка строится на стандартных интерфейсах (ADB/Fastboot) и разборе форматов, поэтому
работает для Samsung, Xiaomi, Motorola, OnePlus, Google Pixel, Huawei/Honor, OPPO/Realme, Vivo,
Infinix/Tecno, ZTE/Nubia и других устройств **в части анализа и подготовки**. Собственные
протоколы производителей не реализованы; для них предусмотрены отдельные модули-заготовки
(плагины), которые можно включать только после проверки подписи и доверия издателю.
