# Мониторинг устройств для шеринга трафика

Диагностическая панель для тех, кто использует Honeygain и похожие сервисы
на нескольких устройствах.

Главная проблема таких «ферм»: **сервис оплачивает только одно устройство
на один публичный IP**. Пять телефонов на одном домашнем Wi-Fi приносят
ровно столько же, сколько один, — и это не лечится кодом.

Это приложение показывает правду: какой у каждого устройства настоящий
публичный IP, кто провайдер, сколько трафика отдано и **сколько устройств
не оплачиваются и почему**.

## Что оно НЕ делает

Здесь нет и не будет:

- подмены или маскировки IP-адреса;
- прокси, VPN, туннелей и «ротации» адресов;
- сокрытия того факта, что устройства находятся за одним роутером;
- подмены геолокации, ASN или любых других сетевых данных.

Это принципиальная граница. Все перечисленные функции существуют только
для обхода антифрод-системы платного сервиса (у Honeygain она называется
HAC — Honeygain Anti-Cheat), нарушают его правила и ведут к блокировке
аккаунта с потерей заработанного. Диагностика — да. Обход — нет.

## Android-приложение

### Скачать APK

Прямая ссылка (откроется на телефоне):

**https://github.com/Klavish777/test/releases/download/apk-latest/app-debug.apk**

Разрешите установку из неизвестных источников для браузера — Android 8.0 и выше.
APK собирается автоматически в GitHub Actions при каждом изменении `android/`
и всегда лежит по одной и той же ссылке.

Если ссылка не открывается или нужна свежая версия:
`https://github.com/Klavish777/test/actions` → последний запуск «Android APK»
→ артефакт **farm-monitor-debug-apk**.

### Что делает приложение

- показывает **настоящий** публичный IP, провайдера, страну и тип подключения
  (Wi-Fi / мобильные данные);
- отправляет отчёт в панель по кнопке и автоматически раз в 15 минут;
- продолжает работать после перезагрузки.

Никаких зависимостей и трекеров — только стандартные API Android, ~20 КБ на APK.

### Настройка

1. Запустите панель на компьютере в той же сети:
   `python -m uvicorn app.main:app --host 0.0.0.0 --port 8000`
2. Узнайте IP компьютера (`ipconfig` / `ifconfig`), например `192.168.1.10`.
3. В приложении введите `http://192.168.1.10:8000`, дайте устройству имя и
   нажмите **Отправить отчёт**.

Android ради экономии батареи может сдвигать фоновые отчёты — для точной
картины отключите оптимизацию батареи для этого приложения.

### Собрать самому

Откройте папку `android/` в Android Studio и нажмите Run, либо из терминала:

```bash
cd android && gradle :app:assembleDebug
```

APK появится в `android/app/build/outputs/apk/debug/`.

## Установка панели

```bash
pip install -r requirements.txt

```

Откройте `http://<IP-компьютера>:8000`.

## Агент для ПК (необязательно)

Если устройства — не телефоны, а компьютеры (Windows, macOS, Linux):

```bash
python agent/agent.py --server http://192.168.1.10:8000 --name "Телефон 1"
```

Агент определяет публичный IP, тип подключения (Wi-Fi / мобильные данные)
и провайдера, затем раз в 10 минут отправляет отчёт в панель.
Проверить без отправки: `python agent/agent.py --once`.

## Что показывают статусы

| Статус | Значение |
|---|---|
| **Оплачивается** | У устройства уникальный публичный IP |
| **Не оплачивается** | Публичный IP совпадает с другим устройством |
| **Дата-центр** | IP принадлежит хостингу/VPS — сервис такие адреса не принимает, это риск бана |

## Как получить реально разные IP — легально

1. **Мобильные данные каждой SIM.** У каждой сим-карты свой IP — это самый
   простой способ получить отдельное подключение для каждого телефона.
2. **Разные физические локации** — дом, дача, квартира родственников.
   Но только с согласия владельца сети и если его провайдер не запрещает
   шеринг трафика.
3. **Больше не надо.** Всё остальное — это попытка обмануть сервис.

## Риски, о которых стоит знать заранее

Трафик клиентов сервиса уходит в интернет **с вашего IP**. Из-за этого:

- провайдер может расценить шеринг как нарушение договора и отключить вас;
- на лимитном тарифе могут списаться деньги за трафик;
- ваш IP может попасть в блэклисты — тогда перестанут открываться банки,
  госсервисы, стриминги;
- участится CAPTCHA.

## Структура

```
android/              — нативное Android-приложение (Java, без зависимостей)
  app/src/main/java/com/example/farmmonitor/
    MainActivity.java    — экран: IP, провайдер, тип подключения, отправка
    Net.java             — определение настоящего IP и POST-отчёт
    Scheduler.java       — автоотчёт раз в 15 минут
    ReportReceiver.java  — фоновый отчёт по будильнику
    BootReceiver.java    — восстановление расписания после перезагрузки
app/
  main.py        — HTTP API и раздача панели
  analysis.py    — правила: кто оплачивается, а кто нет
  store.py       — SQLite
  web/           — интерфейс
agent/agent.py   — агент для ПК (только stdlib)
scripts/         — демо-данные
.github/workflows/android-apk.yml  — автосборка и публикация APK
```
