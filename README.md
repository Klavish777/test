# Work Day

Ежедневник роста канала на YouTube и TikTok. Пять экранов, которые закрывают
четыре задачи: привлечение аудитории, прирост, ускорение роста и активность.

## Скачать APK

Прямая ссылка (открыть в браузере телефона):

**https://github.com/Klavish777/test/releases/download/apk-latest/app-debug.apk**

Android 8.0 и выше, ~40 КБ, без трекеров и без разрешений. APK пересобирается
в GitHub Actions при каждом изменении `android/` и всегда доступен по одной
ссылке.

Запасной путь: `https://github.com/Klavish777/test/actions` → последний запуск
**Android APK** → артефакт **creatorkit-debug-apk**.

## Что делает каждый экран

**День.** Шесть ежедневных действий креатора: снять ролик, записать крючки,
ответить на комментарии, прокомментировать десять чужих роликов в нише,
внести цифры, найти тренд. Считает прогресс дня и серию дней подряд.
Серия важнее идеального дня — закрыл половину, и день не потерян.

**Привлечь.** Крючки для первых трёх секунд, три варианта заголовка,
хэштеги под нишу, стартовые ориентиры по времени публикации и чек-лист
кросс-промо. Отдельная кнопка — кому и что написать для коллаборации:
это самый быстрый легальный источник новой аудитории.

**Рост.** Раз в неделю сохраняете снимок — сколько подписчиков и просмотров.
Приложение считает скорость роста и даёт прогноз на 30 и 90 дней по каждой
площадке отдельно.

**Активность.** Призывы к действию, шаблоны ответов на комментарии, опросы
для аудитории и тексты для закреплённого комментария. Всё это — способы
поднять активность реальных людей, без всяких ботов.

**План.** Сетка публикаций с отметками и аналитика по роликам: вносите
просмотры, лайки, комментарии, репосты — считается вовлечённость и
показывается, какой ролик сработал лучше. Логика простая: повторите лучший
формат серией.

## Граница

Приложение не накручивает просмотры, не запускает авто-лайки и авто-подписки
и не обходит IP. Две причины:

1. **Запрещено правилами.** TikTok прямо запрещает искусственное завышение
   метрик вовлечённости ботами, скриптами и любыми автоматическими методами.
   Последствия — от теневого бана до полной блокировки аккаунта.
2. **Вредит самому каналу.** Алгоритм видит просмотры без досмотра и без
   комментариев, решает, что контент не заходит, и перестаёт показывать
   следующие ролики. Накрутка — это цена за цифру, которая уменьшает
   органический охват.

Шаринг текста в приложении — обычный системный Intent: вы сами отправляете
его людям и туда, куда хотите. Автоматическая генерация просмотров —
принципиально другое, и этого здесь нет.

## Сборка

Открыть `android/` в Android Studio и нажать Run, либо:

```bash
cd android && gradle :app:assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Структура

```
android/app/src/main/java/com/example/workday/
  MainActivity.java  — пять экранов и вся логика
  Content.java       — рутина, крючки, призывы, ответы, коллаборации, ниши
  Generator.java     — сборка текстов и рекомендаций
  Db.java            — SQLite: план, аналитика, снимки роста, рутина дня
.github/workflows/android-apk.yml — автосборка и публикация APK
traffic-panel/       — отдельная панель мониторинга устройств для шеринга трафика
```
